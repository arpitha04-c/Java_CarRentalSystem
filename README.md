# Car Rental System

A console-based Car Rental System developed using Java and Object-Oriented Programming (OOP).

## Features
- View available cars
- Rent a car
- Return a car
- Rental receipt generation
- Input validation
- Automated unit testing with JUnit 5

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- JUnit 5
- Eclipse IDE

## Testing
Includes 9 JUnit 5 test methods across three test classes. All 9 tests pass.

The tests cover:
- Car availability and rental status
- Car rental price calculation
- Customer details
- Car rental and return operations

Test classes:
- `CarTest.java`
- `CustomerTest.java`
- `CarRentalSystemTest.java`

## How to Run
1. Import the project into Eclipse.
2. Add JUnit 5 to the project's build path.
3. Run `Main.java` to start the application.
4. To run the tests, right-click a test class and select **Run As → JUnit Test**.
